📚 Parameter Guide

  • Chunk Size: Maximum characters per text chunk (default: 600). Larger chunks = more context per search result, but less precision. Smaller chunks = more precise matches, but less context. Recommended: 400-800
  • Chunk Overlap: Characters shared between consecutive chunks (default: 100). Prevents losing context at chunk boundaries. Recommended: 50-150
  • Top K: Maximum number of search results to return. Higher = more results (including less relevant). Recommended: 3-10
  • Min Score: Similarity threshold (0-1). Results below this score are filtered out. 0.3 = loose match, 0.7 = strict match. Recommended: 0.3-0.5
